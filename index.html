The period code

Four digits: the year (26), the calendar quarter (1–4, January–March is 1), then the month within that quarter (1–3), or 0 for the whole quarter. These are calendar quarters, not the April tax year.

The code goes in two places: the file name and the Period code box. IRD's tool never checks that they agree, so this page warns you when they don't. An empty box or a code like 2603 makes IRD's tool stop with an error.

Check it with IRD's own tool (Windows only)

  1. Download "Schedule File Verifier Tool" (version 5.20) from ird.gov.lk > Downloads > Tools. Unzip it and open ScheduleFileVerifier.exe.
  2. Click "VAT Schedule Verifier". File Type: "VAT Schedule02".
  3. Period code: type the code shown on this page. It must not be empty.
  4. Browse: pick the .csv file. Don't open it in Excel and save it, because Excel changes dates and numbers. Don't rename it.
  5. Click Verify. "Validation passed!" means you can upload it with the e-filing return. Otherwise the list shows the row (Serial Number) and the reason.
What IRD's tool accepts

File name: {yourTIN}_VAT_SCHEDULE02_{periodcode}_{YYYYMMDD}_ORIGINAL_V{n}.csv, for example 100000016_VAT_SCHEDULE02_2640_20261119_ORIGINAL_V1.csv. Your TIN must have a valid check digit. Upper or lower case is fine. Nothing may be added: … (1).csv from a second browser download is rejected.

Line 1 is this header (any order, any case, exactly these 9 columns):

Serial No,Invoice Date,Tax Invoice No,Supplier's TIN,Name of the Supplier,Description,Value of purchase,VAT Amount,Disallowed VAT Amount

Then one line per invoice. No total row and no blank lines. The tool splits on commas and knows nothing about quotes, so a comma inside a supplier name or description breaks the file, and quotes are kept as part of the value.

ColumnRule
Serial NoWhole number from 1, unique. "01" and "1" count as different.
Invoice DateMonth/day/year, e.g. 10/05/2026 or 10/5/2026. Not after the end of the period.
Tax Invoice NoUp to 40 characters, only A–Z a–z 0–9 _ / -. No spaces or dots. The same number from the same supplier twice is rejected (upper and lower case count as the same).
Supplier's TIN9 digits with a valid check digit. Not your own TIN. Not the VAT number form xxxxxxxxx-7000.
Name of the SupplierUp to 100 characters.
DescriptionUp to 500 characters in the tool (IRD's Excel template says 50).
Value of purchaseUp to 2 decimals, up to 15 digits, not negative.
VAT AmountUp to 2 decimals. Within ±0.99 of value × rate for the invoice date: 18% from 1 Jan 2024 (15% also accepted up to 28 Jan 2024), 15% from Sep 2022 to Dec 2023. 0.00 always passes.
Disallowed VAT Amount0.00 when there is none (blank fails). Not negative, not more than the VAT.

IRD's tool checks in this order and stops at the first step that fails: file name, reading the file, period code, columns and field formats, date format, business rules. Fixing one step can show errors in the next. At most 100 errors are listed.

Rules reverse-engineered from IRD's Schedule File Verifier v5.20 and matched against the real tool on 122 test files. IRD can change its tool at any time; for a final check, run IRD's own verifier.
